SDK Lua do arcanist

Você escreve Lua e o arcanist faz o resto: ler o jogo, andar, atacar, usar item, reagir a evento e desenhar a sua janela. O C++ fica por baixo, você não precisa mexer nele.

Começar em 3 passos Ver exemplos prontos Montar minha UI

Primeiro pack em 3 passos

Pack é uma pasta com um main.lua dentro. O arcanist carrega ela, roda o arquivo e chama o seu ui.frame() a cada quadro.

1. Crie a pasta

Ao lado do arcanist.exe:

scripts/
  meu_bot/
    main.lua

2. Escreva o pack

O mínimo que já faz algo visível:

local E  = require("sdk.engine")
local ui = game.overlay

function ui.frame()
  ui.window("Meu Bot", function()
    local lp = E.localplayer()
    ui.text(lp and ("HP "..lp.hp_pct.."%") or "sem personagem")
  end)
end

3. Carregue

Na janela do arcanist, aba SDK Lua:

Carregar

Precisa de pack novo na lista? Rescan. Mudou o código? Reload.

Sem personagem no jogo o SDK não sobe. Ele liga junto com o attach do bot no cliente — se a aba mostrar “host: parado”, entre no personagem primeiro.

O modelo mental: dois estados

O main.lua roda em dois lugares ao mesmo tempo. É a parte que mais confunde no começo, então vale ler com calma.

EstadoThreadO que vive aqui
logic do script (~20 ms) Engine.on, timers, coroutines, ações síncronas
ui da GUI (por quadro) só o ui.frame() — desenha e enfileira ações

Por que dois? Uma ação no cliente trava a thread que chamou, até 2 segundos, esperando o jogo responder. Se fosse a UI chamando, a janela congelava. Por isso a UI só pede e o logic executa.

Eles não compartilham variáveis

Uma local do logic não existe na ui. Use a ponte:

local S  = require("sdk.shared")   -- memória (some ao fechar)
local ST = require("sdk.storage")  -- DISCO (sobrevive ao restart)

Engine.on("Hp", function(ev) S.set("hp", ev.pct) end)

function ui.frame()
  ui.text("HP: " .. tostring(S.get("hp") or "?"))
end

Sabendo onde você está: HOST_STATE vale "logic" ou "ui", e game.is_ui é boolean. Use isso para não inicializar duas vezes:

if HOST_STATE == "logic" then
  ST.set("sessoes", (tonumber(ST.get("sessoes")) or 0) + 1)
end

Leitura

O que dá pra ler do jogo. Só leitura, nada é escrito no cliente.

E.localplayer()tabela · nil, err id, name, x, y, z, hp, hp_max, hp_pct, mana, mana_max, mana_pct, cap, dir, level, xp, stamina, alive, poisoned, paralyzed, hasted, manashielded, in_pz, drunk
E.creatures()lista id, name, x, y, z, dist, hp_pct, is_self, is_player (só outros), is_monster, is_npc, skull
E.creature(id)tabela · nil Uma criatura específica.
E.target()number Id da criatura que você está atacando. 0 = sem alvo.
E.equipment()tabela · nil, err Itens equipados por slot (só os ocupados): helmet, amulet, backpack, armor, right (arma), left (escudo), legs, boots, ring, ammo. Cada item tem id e count — ex.: eq.helmet.id.
K.open()lista · nil, err Containers abertos (mochila, bps, depot): cada um com {id, name, capacity, items = {{slot, id, count}, ...}}. Fail-closed: sem jogo devolve erro.

Tipos são nativos. Números chegam como number e condições como boolean — então if lp.hp_pct < 40 then e if lp.in_pz then funcionam como você espera (nada de comparar string).

Helper / RTC — configurar o auto do bot

Auto-target, auto-cast de magias e runas, cura, poções, sio, haste. Você não precisa decorar os nomes: H.list() devolve o catálogo e você monta o painel em cima dele.

for _, f in ipairs(H.list()) do
  local v = H.get(f.name)
  if f.type == "u8" and f.max == 1 then
    local novo = ui.checkbox(f.label, v ~= 0)
    if novo ~= (v ~= 0) then H.set(f.name, novo and "1" or "0") end
  else
    local novo = ui.slider(f.name, v, f.min, f.max)
    if novo ~= v then H.set(f.name, tostring(novo)) end
  end
end

A primeira leitura é baseline — não emite evento (evita rajada ao entrar no mundo). Handlers rodam no estado logic, dentro do tick; um handler que quebra é isolado e logado — os outros continuam.

Timers e coroutines

Coroutine é o jeito de escrever feature: você escreve em linha reta e o wait devolve o controle.

Engine.spawn(function()
  while true do
    wait(1000)                       -- volta no próximo tick
    if S.get("ligado") then
      local lp = E.localplayer()
      if lp and lp.hp_pct < 60 then L.say("exura") end
    end
  end
end)
FunçãoPara que
Engine.spawn(fn)Roda fn numa coroutine; devolve id.
wait(ms)Pausa a coroutine. Só dentro de spawn — fora dá erro de propósito.
Engine.every(ms, fn) / after(ms, fn)Timer periódico / uma vez.
Engine.cancel(id)Para coroutine, timer ou handler.
Engine.now()Milissegundos monotônicos.

Armadilha clássica: while true do wait(500) end no corpo do script (fora do spawn) giraria para sempre e travaria o carregamento. Por isso o wait fora de coroutine é erro, não “retorna false”.

Grava em scripts/<pack>/storage.dat a cada mudança. É onde vive a config do usuário final.

ST.del(k) · ST.all() · ST.save()
-- o padrão de UI de produto: lê com default, grava quando o usuário mexe
local curar = tonumber(ST.get("curar_pct")) or 60

function ui.frame()
  local novo = ui.slider("Curar abaixo de %", curar, 10, 95)
  if novo ~= curar then
    curar = novo
    ST.set("curar_pct", novo)   -- sobrevive ao restart
  end
end

Um painel completo

local ui = game.overlay
local ST = require("sdk.storage")

function ui.frame()
  ui.window("Meu Bot", function()

    -- tabela de stats (sem boilerplate de coluna)
    local lp = E.localplayer()
    if lp then
      ui.table("##stats", {"Pos", "HP", "Mana"}, {{
        ("%d,%d,%d"):format(lp.x, lp.y, lp.z),
        ("%d%%"):format(lp.hp_pct),
        ("%d%%"):format(lp.mana_pct),
      }})
    end

    -- seção colapsável com config persistida
    ui.collapsing("Automação", function()
      local on = ui.checkbox("Auto-loot", ST.get("loot") == true)
      if on ~= (ST.get("loot") == true) then
        ST.set("loot", on)
        game.alert(on and "Auto-loot ligado" or "desligado")
      end
    end)

    -- a UI do bot (abas) sai da frente SOZINHA quando o pack desenha janela
  end)
end

Regras da UI: o ui.frame() roda a cada quadro — nada de trabalho pesado nem laço dentro dele. Estruturas (window, collapsing, child) sempre fecham, mesmo se o corpo der erro: o layout não corrompe.

A UI do bot sai da frente sozinha: quando o teu pack desenha uma janela, as abas do bot (Engine/Cavebot/Debug) desaparecem automaticamente — o usuário final vê só o teu painel. Não existe hide_host: não precisa de nenhuma chamada no script. Se o pack não desenhar nada, as abas voltam (você nunca fica sem acesso). INSERT (tecla global) alterna a UI do bot quando você (dev) for carregar/recarregar packs ou usar o Debug.

game.dbg — ferramenta de pesquisa

Leitura crua de memória, para investigar e validar. Não use em script de produção.

Hotkey global (funciona com o jogo em foco)

-- no ui.frame: F1 liga/desliga o auto-loot, mesmo com o jogo em foco.
-- game.key_pressed consome a borda (dispara 1x) — chame num lugar só.
function ui.frame()
  if game.key_pressed("f1") then
    local on = not (ST.get("loot") == true)
    ST.set("loot", on)
    game.alert(on and "Auto-loot ON" or "Auto-loot OFF")
  end
  ui.window("Meu painel", function()
    ui.text("F1 liga/desliga o auto-loot · INSERT mostra/esconde a UI do bot")
  end)
end

Teclas: f1..f12, insert, delete, home/end, pageup/pagedown, setas, space, enter, escape, tab, a..z, 0..9. A leitura é global: funciona com o jogo em foco, sem precisar do bot focado. game.key(nome) = está pressionada agora; game.key_pressed(nome) = acabou de apertar (borda, consumida na leitura).

heal/main.lua — cura automática (magia e % salvos)

local E  = require("sdk.engine")
local L  = require("sdk.localplayer")
local ST = require("sdk.storage")
local S  = require("sdk.shared")
local ui = game.overlay

local cfg = {
  ligado = (ST.get("ligado") == true),
  spell  = ST.get("spell") or "exura",
  hp_min = tonumber(ST.get("hp_min")) or 60,
}

-- FEATURE (estado logic). Le os toggles do ST a cada volta: o que o usuario
-- mexe na janela chega aqui na hora (as variaveis de cada estado NAO se cruzam).
spawn(function()
  while true do
    wait(300)
    if ST.get("ligado") == true then
      local lp = E.localplayer()
      local limiar = tonumber(ST.get("hp_min")) or 60
      if lp and lp.hp_pct < limiar then
        local spell = ST.get("spell") or "exura"
        local ok, err = L.say(spell)
        if ok then
          S.set("ultima_cura", lp.hp_pct .. "% com " .. spell)
        else
          S.set("ultimo_erro", tostring(err))
        end
      end
    end
  end
end)

-- UI (estado ui)
function ui.frame()
  ui.window("Heal", function()
    local lp = E.localplayer()
    if lp then
      ui.text(("HP %d%%   Mana %d%%"):format(lp.hp_pct, lp.mana_pct))
      ui.progress(lp.hp_pct)
    else
      ui.text("sem personagem")
    end

    ui.separator()

    local v = ui.checkbox("Cura automatica", cfg.ligado)
    if v ~= cfg.ligado then
      cfg.ligado = v
      ST.set("ligado", v)
      game.alert(v and "Heal LIGADO" or "Heal desligado")
    end

    local pct = ui.slider("Curar abaixo de (%)", cfg.hp_min, 10, 95)
    if pct ~= cfg.hp_min then
      cfg.hp_min = pct
      ST.set("hp_min", pct)
    end

    local sp = ui.input("Magia", cfg.spell)
    if sp ~= cfg.spell then
      cfg.spell = sp
      ST.set("spell", sp)
    end

    local ult = S.get("ultima_cura")
    if ult then ui.color_text(0.4, 1.0, 0.4, "ultima cura: " .. tostring(ult)) end
    local err = S.get("ultimo_erro")
    if err then ui.color_text(1.0, 0.6, 0.3, "ultimo erro: " .. tostring(err)) end
  end)
end

hud/main.lua — painel de stats

local E  = require("sdk.engine")
local ST = require("sdk.storage")
local ui = game.overlay

-- conta quantas vezes o bot carregou este pack (fica salvo no disco)
if HOST_STATE == "logic" then
  ST.set("sessoes", (tonumber(ST.get("sessoes")) or 0) + 1)
end

function ui.frame()
  ui.window("HUD", function()
    local lp = E.localplayer()
    if not lp then
      ui.text("sem personagem (loga no jogo)")
      return
    end

    ui.text(("%s  -  nivel %d"):format(lp.name, lp.level))
    ui.text(("Pos: %d, %d, %d"):format(lp.x, lp.y, lp.z))
    ui.separator()

    ui.text(("HP %d%%"):format(lp.hp_pct))
    ui.progress(lp.hp_pct)
    ui.text(("Mana %d%%"):format(lp.mana_pct))
    ui.progress(lp.mana_pct)
    ui.separator()

    ui.text("Cap: " .. lp.cap .. "   |   XP: " .. lp.xp)
    ui.text("Stamina: " .. lp.stamina)

    local estados = {}
    if lp.poisoned then estados[#estados + 1] = "ENVENENADO" end
    if lp.paralyzed then estados[#estados + 1] = "PARALISADO" end
    if lp.hasted then estados[#estados + 1] = "haste" end
    if lp.manashielded then estados[#estados + 1] = "manashield" end
    if lp.in_pz then estados[#estados + 1] = "PZ" end
    if lp.drunk then estados[#estados + 1] = "bebado" end
    if #estados > 0 then
      ui.color_text(1.0, 0.75, 0.2, table.concat(estados, "  |  "))
    else
      ui.text("sem condicoes ativas")
    end

    ui.separator()
    ui.text("sessoes (salvo): " .. tostring(ST.get("sessoes") or "?"))
  end)
end

autoloot/main.lua — auto-loot com botões

local T  = require("sdk.tools")
local ST = require("sdk.storage")
local S  = require("sdk.shared")
local ui = game.overlay

local cfg = {
  ligado    = (ST.get("ligado") == true),
  intervalo = tonumber(ST.get("intervalo")) or 1500,
}

-- FEATURE (estado logic). Le do ST a cada volta (toggle da UI chega na hora).
spawn(function()
  while true do
    wait(tonumber(ST.get("intervalo")) or 1500)
    if ST.get("ligado") == true then
      local ok, err = T.quickloot()
      if ok then
        S.set("loots", (tonumber(S.get("loots")) or 0) + 1)
      else
        S.set("ultimo_erro", tostring(err))
      end
    end
  end
end)

    end

    ui.separator()

    if ui.button("Lootar agora") then
      local ok, err = T.quickloot()
      game.alert(ok and "Loot ok" or ("Falhou: " .. tostring(err)))
    end

    ui.text("loots nesta sessao: " .. tostring(S.get("loots") or 0))

  end)

radar/main.lua — monstros por perto + atacar

local E  = require("sdk.engine")
local L  = require("sdk.localplayer")
local ui = game.overlay

function ui.frame()
  ui.window("Radar", function()
    local perto = {}
    for _, c in ipairs(E.creatures()) do
      if c.is_monster then perto[#perto + 1] = c end
    end
    table.sort(perto, function(a, b) return a.dist < b.dist end)

    ui.text(#perto .. " monstro(s) por perto")
    ui.separator()

    if #perto == 0 then
      ui.text("nenhum monstro na tela")
      return
    end

    for i = 1, math.min(#perto, 8) do
      local c = perto[i]
      ui.text(("%s  (%d tiles, %d%% hp)"):format(c.name, c.dist, c.hp_pct))
      ui.same_line()
      -- o clique enfileira a acao (a UI nunca despacha na hora); erro real vai pro log
      if ui.button("Atacar##m" .. c.id) then
        local ok, err = L.attack(c.id)
        game.alert(ok and ("Atacando " .. c.name) or ("Falhou: " .. tostring(err)))
      end
    end
  end)
end
